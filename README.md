# Python Mini Projects

A collection of Python mini projects created while learning and practicing Python programming.

## Projects

| Project | Description |
|---------|-------------|
| [ATM Simulator](ATMsimulator.py) | Simulates basic ATM operations such as PIN verification, balance checking, deposit, withdrawal, and PIN change. |
| [Contact Book](contactbook.py) | A simple program to store and manage contact information. |
| [Expense Tracker](expensetracker.py) | A basic program for recording and tracking expenses. |
| [Library System](librarysystem.py) | A simple library management program for managing books and basic library operations. |
| [Password Strength Checker](passstrengthcheck.py) | Checks the strength of a password based on different conditions. |
| [Quiz Game](quizgame.py) | A simple quiz game that asks questions and calculates the user's score. |
| [Random Guess Number](randomguessno.py) | A number guessing game where the user tries to guess a randomly generated number. |
| [Random Password Generator](randompassword.py) | Generates random passwords using different characters. |
| [Rock Paper Scissors](rockpaperscissor.py) | A command-line game where the user plays Rock Paper Scissors against the computer. |
